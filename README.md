# IGN_assistant-route

This plugin helps users edit the attributes of BDTopo road segments while applying semantic consistency checks to all changes.

## Pré-requis

Mandatory : The "plugin\_maitre" must be installed.
Link to the plugin maître : [maitre-qgis-plugin sur GitHub](https://github.com/IGNF/maitre-qgis-plugin)

## Fonctionnalités

French : 
* Visualisation des valeurs d'attributs d'un tronçon de route BDTopo
* Modification de certains attributs d'un tronçon de route BDTopo
* Affichage du sens de numérisation d'un tronçon de route
* Affichage du chemin le plus court entre 2 tronçons de route


English :
* Display of attribute values for a BDTopo road segment.
* Editing selected attributes of a BDTopo road segment.
* Display of the digitizing direction of a road segment
* Display of the shortest path between two road segments.
